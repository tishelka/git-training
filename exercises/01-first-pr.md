# Задание 1. Первый Pull Request

**Цель:** скачать общий репозиторий, создать свою ветку, добавить файл, сделать коммит и открыть Pull Request.

Это первое задание. Не бойтесь ошибиться: в README есть подробный разбор всех шагов.

## Что сделать

1. Установите Git и VS Code, настройте имя и email — как в [README](../README.md).
2. Клонируйте репозиторий:

```bash
git clone https://github.com/tishelka/git-training.git
cd git-training
```

3. Создайте ветку — **вместо `yourname` используйте свой ник**:

```bash
git switch -c practice/yourname-profile
```

4. Откройте [образец](../students/_example.md) и создайте файл `students/yourname.md`. Добавьте ник, роль, чему хотите научиться и любимый досуг. Не трогайте чужие файлы.
5. Сохраните изменение:

```bash
git status
git add students/yourname.md
git commit -m "Add yourname profile"
git push -u origin practice/yourname-profile
```

6. На GitHub откройте PR **из вашей ветки в `master`**. Название: `Add yourname profile`.
7. Заполните шаблон PR и попросите руководителя посмотреть результат.

## Как проверить себя

- [ ] Ветка называется не `master`.
- [ ] В `students/` появился отдельный файл с моим ником.
- [ ] `git status` после коммита не показывает забытых изменений.
- [ ] В PR виден только мой файл, а не чужие правки.
- [ ] PR направлен в `master`.

**Не нужно:** делать fork, если у вас есть доступ к репозиторию; редактировать чужие анкеты; отправлять PR из `master`.

Если `git push` пишет про отказ в доступе, убедитесь, что вы приняли приглашение в репозиторий. Если приглашения нет, попросите руководителя добавить вас или используйте fork по согласованию.
